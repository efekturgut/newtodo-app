📝 Todo App

Basit ve kullanışlı bir Todo (Yapılacaklar Listesi) uygulaması.
Kullanıcıların görev eklemesine, düzenlemesine, silmesine ve tamamlandı olarak işaretlemesine olanak sağlar.

🚀 Özellikler

➕ Yeni görev ekleme

✏️ Görev düzenleme

❌ Görev silme

✅ Görev tamamlama

🔍 Görev arama

📂 Filtreleme (All / Active / Done)

💾 LocalStorage ile verileri tarayıcıda saklama

🛠️ Kullanılan Teknolojiler

HTML5

CSS3

JavaScript (Vanilla JS)

LocalStorage
